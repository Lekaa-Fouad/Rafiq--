# Rafiq – رفيق
An AI assistant project designed to support visually impaired users inside the home using computer vision and voice commands.

---

## 🎯 Project Overview
Rafiq is a smart assistant that empowers visually impaired users by combining:
- **OCR + Text-to-Speech**: Read printed text aloud.
- **Object Detection**: Identify obstacles and household items.
- **Face Recognition**: Recognize familiar people.
- **Indoor Mapping**: Navigate safely inside the home.
- **Voice Commands**: Simple and intuitive control.
